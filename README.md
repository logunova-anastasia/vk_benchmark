# Black Myth: Wukong Benchmark Runner

Локальная утилита на **C# (.NET 8, Windows)** для автоматического проведения двух запусков **Black Myth: Wukong Benchmark Tool (Steam)**. Сама применяет настройки, запускает оба теста, распознаёт итоговые FPS с экрана и сохраняет отчёт с характеристиками компьютера.

## Требования

- Windows 10/11, Steam и установленный **Black Myth: Wukong Benchmark Tool**.
- **.NET 8 SDK** для запуска исходников через `run.bat`.
- Английский язык интерфейса бенчмарка и английский компонент распознавания текста Windows (Windows OCR).
- Перед первым запуском утилиты **один раз откройте Benchmark Tool вручную**, примите условия, завершите начальную настройку и закройте его.
